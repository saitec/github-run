# 🌱 daily

**one fix. one insight. every day.**

a public notebook of things i ship while building [ShopOS](https://shopos.ai) and [SeeIt](https://5aitec.com).
written by me, helped by Claude, reviewed before anything goes out.

### the loop

```
        ☕ morning
           │
   ┌───────┴────────┐
   ▼                ▼
 🔧 FIX            💡 INSIGHT
 find one real     pick one thing
 open-source bug   i learned yesterday
   │                │
 patch + tests     turn it into a
 + PR draft        skill, note or tool
   │                │
   └───────┬────────┘
           ▼
     👀 sai reviews
           │
     ✅ ship it ──► PR goes upstream
                    insight goes public
                    graph stays green 🟩
```

### what lives where

| folder | what's inside |
|---|---|
| 🔧 [`fixes/`](fixes) | one folder per day. the patch, the tests, the PR text, the link once it's sent. |
| 💡 [`insights/`](insights) | short notes. one idea each. written like i talk. |
| 🧠 [`skills/`](skills) | reusable Claude skill files pulled from real work. drop them in `~/.claude/skills/`. |
| 🦕 [`revivals/`](revivals) | my 2016 repos, brought back to life one by one. |
| 📒 [`LOG.md`](LOG.md) | the running diary. one line per day. |

### the rules

1. **Real bugs only.** No drive-by typo PRs. Maintainers' time is precious.
2. **Tests or it didn't happen.** Every fix runs the repo's own tests first.
3. **Small diffs.** If it's bigger than an afternoon, it's an issue, not a PR.
4. **Say AI helped.** Every PR says so. Honest beats clever.
5. **Nothing private goes public.** See [RULES.md](RULES.md).
6. **Sai ships, not the bot.** Every PR and post waits for a 👍.
